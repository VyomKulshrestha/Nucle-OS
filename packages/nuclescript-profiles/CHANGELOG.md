# Changelog

## 0.2.0

- Added typed IDT oPools schemas and a matching simulation helper.
- Aligned IDT defaults with the compiler's 3x redundancy and 0.05% error model.

## 0.1.0

- Initial `@nuclescript/profiles` package release.
- Added `illumina_standard`, `illumina_high_coverage`, `nanopore_standard`,
  `nanopore_high_coverage`, and `twist_standard` pool schema exports.
- Added `recommended_pool_for_illumina`, `recommended_pool_for_nanopore`, and
  `recommended_pool_for_twist` function exports.
